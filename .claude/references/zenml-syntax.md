# Zenithal Markup Language (ZenML, `.zml`) 構文リファレンス


原稿ファイル `document/**/*.zml` で使われている記法の言語仕様。
XML と等価な構造を TeX 風の構文で書く形式で、パーサは `@zenml/zenml` (このリポジトリの `node_modules/@zenml/zenml/document/syntax.md` に原典あり)。
**ここに書かれているのは「構文」だけであるため、どのタグが使えるかは `.claude/references/avendia-zenml-spec.md` を参照すること**。

## 基本
### 要素
```
\tag<内容>                       →  <tag>内容</tag>
\tag|attr="value",foo="bar"|<内容>  →  <tag attr="value" foo="bar">内容</tag>
\tag|boolean|<内容>              →  <tag boolean="boolean">内容</tag>
\tag;                            →  <tag/>
\tag|attr="value"|;              →  <tag attr="value"/>
```

- 属性値は必ず `"` で囲む (`'` は不可)。
- 属性は `,` 区切り。値を省略すると属性名と同じ値になる (真偽値属性)。
- 空要素は `\tag<>` ではなく `\tag;` と書くのが通例。
- 入れ子は XML と同様に自由。

### タグ名に付けるマーク (接尾辞)
| マーク | 意味 |
| --- | --- |
| `*` | 内容の各行から、最もインデントの浅い行と同じ量の先頭空白を削る。`\pre` などで使う。 |
| `~` | 内容をテキストとして扱い、要素やマクロを解釈しない (CDATA 相当)。エスケープ文字は有効なままなので、内容に `>` を含めるときは `` `> `` と書く。 |
| `+` | 直後に続く同名要素の名前を省略できる。`\tag+<AAA><BBB>` → `<tag>AAA</tag><tag>BBB</tag>`。属性を付けた場合は全要素が同じ属性を持つ。 |

`*` と `~` は併用可 (順不同)。
`\pre~*<...>` はプログラムコードを貼るときの定型。

`+` マークなしで `\tag<a><b>` のように内容ブロックを 2 つ以上書くとパースエラーになる。
複数ブロックを取れるのはマクロ (`&名前`) と数式内 (Zotica) の要素だけ。

### 処理命令・宣言
```
\xml?|version="1.0",encoding="UTF-8"|;   →  <?xml version="1.0" encoding="UTF-8"?>
\zml?|version="1.1"|;                    →  (出力されない ZenML 専用の宣言)
```
処理命令はタグ名の末尾を `?` にする。
疑似属性形式で書くときは `,` 区切りかつ末尾 `;` が必須。

### エスケープ
バッククォート `` ` `` を前置してエスケープする。対象は次の文字:
```
&  <  >  ;  "  {  }  [  ]  /  \  |  `  #
```

テキスト中でも属性値中でも使える (例: `` `< `` → `<`, `` `> `` → `>`, `` `[ `` → `[`)。
数式中の不等号 (`` &m<x `> 0> ``) やリテラルの角括弧はこの形で書く。

### 特殊タグ
`{…}`, `[…]`, `/…/` は特別な要素に変換される。
このリポジトリでの割り当ては `generator/generator.ts` の `createParser()` で指定されている:

| 記法 | 要素 | 用途 |
| --- | --- | --- |
| `{…}` | `\x` | シャレイア語やフェンナ語の文字列 (単語ごとに分割される) |
| `[…]` | `\xn` | 同上だが分割しない (転写・音素・記号など) |
| `/…/` | `\i` | 斜体の変数 |

数式 (Zotica) の中では 3 つとも「グループ化」の意味になる。

### マクロ
`\` の代わりに `&` を前置するとマクロになる。
変換規則はパーサに登録されたプラグイン (`plugin/` 以下) が決める。
このリポジトリで使えるマクロは `.claude/references/avendia-zenml-spec.md` を参照。

### コメント
```
#<コメント>      →  <!-- コメント -->
## 行コメント     →  <!-- 行コメント -->
```

### CDATA・DOCTYPE
CDATA セクションは無い (`~` マーク付き要素で代用)。
DOCTYPE 宣言は記述できない。

## 定型のファイル冒頭
`.zml` ファイルは次の 2 行から始めるのが決まり (既存ファイルの大半は UTF-8 BOM 付きだが、BOM は変換時に除去される):

```
\zml?|version="1.1"|;
\xml?|version="1.0",encoding="UTF-8"|;
```
