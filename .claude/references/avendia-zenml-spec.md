# Avendia の .zml タグリファレンス


`document/**/*.zml` で使える主なタグの一覧。
構文そのものは `.claude/references/zenml-syntax.md` を参照。

よく使われるタグのみを抜粋して記載してあるので、**全てのタグがここに書かれているわけではない**。
実装が `template/` 以下 (`template/index.ts` が全マネージャの登録順) と `plugin/` 以下にあるため、正確なタグの存在を確かめたい場合はこれを参照すること。

**登録されていないタグはエラーにならず黙って消える** (`template/fallback.ts` が未登録要素を空にするため)。
タグ名や属性名がうろ覚えのときは、必ず `template/` を grep するか既存の `.zml` から用例を探すこと。

## 1. ページの骨格
`.zml` はファイル冒頭の 2 行 (`\zml?` と `\xml?`) の後、次のどちらかの要素をルートに持つ。

### `\page<...>` — 通常ページ
サイト共通のヘッダ・パンくず・フッタが `template/template.html` によって自動的に付く。
本文はこの中に直接書く。
ほぼ全ての `.zml` はこちら。

### `\html|lang="ja"|<...>` — 生 HTML ページ
トップページや各セクションのトップなど、独自レイアウトのページで使う。
**このスコープでは未知のタグも属性ごとそのまま HTML として出力される** ので、`\div`, `\span`, `\meta`, `\wbr` などを自由に書ける。
`\head<...>` の中身はそのまま `<head>` になり、アナリティクスのスクリプトだけ自動で追加される。
`\common-footer;` で共通フッタを挿入できる。

## 2. `\page` の直下に置くメタ要素
本文としては出力されず、ページの設定として使われる。慣例的に本文の前にまとめて書く。

- `\name<ページ名>` — パンくず末尾・`<title>`・OGP タイトルになる。原則として必須。
- `\ver<バージョン>` — 人工言語の対応バージョン表記。
- `\series|num="…",prev="…",next="…"|<シリーズ名>` — 連載ナビゲーションを本文の上に出す。
- `\license<…>` — フッタのライセンス表記。省略するとデフォルトとして `CC BY-NC-ND 4.0` 扱いになる。`none` を指定すると「Creative Commons 対象外」の表記になる。
- `\use-math;` — 数式用の CSS と JS を埋め込む。`&m`, `&mb` を使うページでは必須。`\use-math|prefix="…"|;` で定理環境に接頭辞が付く。
- `\use-script|src="…"|;` — `program/script/` 以下のスクリプトを読み込む。
- `\use-hiero;` — ヒエログリフ表示 (hierojax) を有効化する。`\hr`, `\hrs` を使うページでは必須。
- `\base|href="…"|;` — `<base>` を出力。エラーページのみで、基本は使用しない。

## 3. ブロック要素
### 見出し・段落
- `\h1<...>`, `\h2<...>`, `\h3<...>` — セクション。3 段階まで利用できる。
  - `tag="sss"` — 参照用のタグ。`#SSS` のように表示され、`id` にもなる (`\rref` の参照先)。
  - `num="1.2"` — `§1.2.` のように表示され、`id` にもなる。
  - `id="..."` — `id` のみ直接設定する。
- `\hsep;` — 節区切りの水平線。基本的には製作日記 (`diary/`, `*-diary/` 直下のファイル) でのみ用いる。
- `\p<...>` — 段落。
  - `num="3"` — 段落番号。
- `\todo<...>` — 「執筆中」等の注意書きボックス。

### リスト
- `\ul<\li<...>>`, `\ol<\li<...>>` — 箇条書き (`ol` は番号付き)
  - `col="2"`, `col="3"` — 箇条書き全体を段組化。
- `\el<\li<\et<見出し>\ed<説明>>>` — 定義リスト。
- `\trans<\li<\ja<原文>\sh<訳文>>>` — 対訳リスト。
- `\xl<...>`, `\xol<...>` — 例文リスト (`xol` は番号付き)。
- `\ql<...>` — 問題リスト。

例文リストの例:
```
\xl<
  \li|tag="abc"|<
    \sh<{人工言語の例文}>
    \gloss<...>
    \ja<日本語訳>
  >
>
```

### グロス (逐語訳)
- `\gloss<...>` — グロス全体。`\xl` の `\li` の中にも直接置ける。
- `\li<...>` — 1 語分の情報。
- `\sh<...>` — 語形。
- `\bs<...>` — 基本形・辞書形。
- `\ex<...>` — 語釈。
- `\mph<...>` — 形態素情報。
- `\gls<...>` — 語の区切り記号。`\gls|sp|` とすると前後に空きを入れる (接語に対して指定する)。
- `\glp<...>` — 句読点類。

グロス内の生のテキスト (改行やインデント) は無視されるので、`\li` を改行して並べて良い。

グロスの例:
```
\gloss<
  \li<\sh<{веждо̂с}>\bs<{веждо̂с}>\ex<貧する\mph<|能.現.三.定.赤>>>
>
```

### 表・図
- `\table<\caption<...>\tr<\th<...>\td<...>>>` — 表。
  - `row="2"`, `col="3"` 等 — `\th` や `\td` に指定することでセル結合できる。
- `\img|src="..."|;` — 画像。
- `\side<...>` — 図表コンテナ。中に `\img` や `\table` を複数入れて 1 つの枠にまとめる。

### プログラム
- `\pre` — 行番号付きのソースコード。`\pre|simple|` とすると行番号が消える。
- `\samp` — 実行結果。`\pre` の直後に置く。

これらは中身をそのまま表示させたいので、`~*` マーク (テキスト扱い＋インデント除去) を付けるのが通例。

プログラムの例:
```
\pre~*<
  const x = 1;
>
\samp<
  output
>
```

### 目次ページ用
記事一覧ページ (`…/index.zml`) で使う。

- `\hb<...>` — 一覧の見出し
- `\pb<...>` — 一覧のコンテナ
- `\ab|href="",date=""|<...>` — 項目。`date` が数字だけならハイリア日付として表示される。
- `\abo`, `\aba` — 「旧」「古」マーク付きの項目
- `\abd` — リンクにしない (準備中) 項目

目次ページの例:
```
\hb<7 代 3 期>
\pb<
  \ab|href="345.html",date="5062"|<記事タイトル>
>
```

### 数学関連
- `\thm|type="thm",id="gen"|<\name<定理名>...>` — 定理環境。番号は自動的に付けられる。
  - `type` は `def` (定義), `thm` (定理), `prp` (命題), `lem` (補題), `cor` (系), `axm`(公理) のいずれか。
- `\prf<...>` — 証明。

## 4. インライン要素

### 人工言語・文字
- `{...}` (= `\x`) — シャレイア語やフェンナ語の表現。単語ごとに `span` に分割され、辞書ポップアップの対象になる。
- `[...]` (= `\xn`) — 上記の分割しない版。
- `/.../` (= `\i`) — 斜体の変数。
- `\h<5062>` — ハイリア日付 (先頭に `H` が付く)。
- `\part<2>` — 第 N 部の表記 (先頭に `#` が付く)。
- `\fl<foreign>` — 外国語表記。自動で丸括弧が付き文字が小さくなる。
- `\rd<...>` — 語根。
- `\sbr<...>` — 上付きの略記。フェンナ語でのみ用いる。
- `\cn<...>`, `\cns<...>`, `\cnbr<...>` — 楔形文字 (それぞれ 1 語, 文, 改行)。
- `\hr<...>`, `\hrs<...>` — ヒエログリフ (それぞれ 1 語, 文)。内容は拡張 MdC 表記。`\use-hiero;` が必要。

### 書式
- `\c<...>` — コード。
- `\m<...>` — 等幅。**マクロの `&m` (数式) とは別物なので注意**。
- `\sc<...>` — スモールキャピタル。
- `\sup<...>`, `\sub<...>` — 上付き, 下付き。
- `\small<...>` — 小さい文字。
- `\k<...>` — 日本語約物 (`\k<…>` のように三点リーダなどに使う)。
- `\nw<...>` — 折り返し禁止箇所。明示的に指定しないと意図しない箇所で折り返されてしまうような部分でのみ用いる。
- `\url<...>` — URL 表示。
- `\box|num="1"|<...>`, `\box|tag="abc"|<...>` — 囲み記号。番号付き例文リスト (`\xol`) もしくは問題リスト (`\ql`) の項目を参照するときに用いる。
- `\red|len="4"|<...>` — 伏字。
- `\lys;` — 歌詞用の空白。

### リンク・参照
- `\a|href="..."|<...>` — リンク。
- `\ae|href="..."|<...>` — 常に別タブで開くリンク。外部サイトへのリンクはこれを用いる。
- `\an|href="..."|<...>` — 装飾なしのリンク。
- `\rref|ref="ssi"|;` — 文法書の節への参照 (`#SSI` と表示)。参照先は `\h1|tag="ssi"|` 等で指定する。
- `\rterm|key="てんしゃ",id="transliteration"|<転写>` — 用語の定義箇所。`key` は索引での読み。
- `\mref|type="thm",ref="gen"|;` — 定理, 式, 文献への参照。`type` はそれぞれ `thm`, `eq`, `bib` を指定する。
- `\def<...>` — 定義される語 (鉤括弧で囲まれ強調される)。

## 5. マクロと数式
- `&m<...>` — インライン数式 (Zotica)。
- `&mb<...>` — ブロック数式。`&mb|id="eq1"|<...>` とすると番号が付き、`\mref|type="eq",ref="eq1"|;` で参照できる。
- `&mark<...>` — ブロック数式の右端に付ける数式番号や印。
- `&raw<...>` — 中身をそのまま出す。

数式を使うページには `\use-math;` が必要。

### Zotica (数式) の記法
`&m<...>` の内部は Zotica という別の言語で、ZenML と同じ構文で数式を書く。

Zotica の記号名を網羅した一覧表はリポジトリ内にはない。
名前を確かめたいときは `node_modules/@zenml/zotica/dist/index.js` の記号テーブル (`"operator"` などのキー) を検索するか、`document/ja/other/mathematics/` 以下の既存ファイルから用例を探すのが早い。

## 6. スコープについて (テンプレートを触るとき)
`template/` の各ルールは `registerElementRule(タグ名, スコープ, 変換関数)` で登録されている。
スコープは `page`, `page.ul`, `page.xl.li`, `page.gloss`, `page.table.tr`, `head`, `navigation`, `html`, `reference-section` など様々ある。
スコープは単なる文字列だが、ネストの意味で `.` 区切りの名前を使う慣習になっている。
同じタグ名でもスコープごとに実装が違う (例: `\li` は `page.ul`, `page.el`, `page.xl`, `page.gloss`, `page.ql` 内部で別物)。

新しいタグを足すときは `template/` 内の適切なファイルにルールを追加し、新規ファイルなら `template/index.ts` にマネージャを登録する。
ブロック要素には `self.setBlockType(上, 下)` に `"bordered"` もしくは `"text"` を指定して前後の余白を整える。
